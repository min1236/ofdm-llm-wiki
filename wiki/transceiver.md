# OFDM 的傳送與接收流程

> 類型：LLM 整合的知識頁 | 最後整理：2026-11-22

## 核心概念
發送端：位元 → QPSK/QAM 映射 → 子載波排列 → IFFT → 加上 CP → 傳送。接收端：接收 → 同步 → 移除 CP → FFT → 等化 → 解映射。IFFT 把頻域的子載波資料合成時間域樣本；FFT 反過來還原各子載波頻域符號。

## 教學提醒
IFFT / FFT 為有效率的實作工具；不是把訊號「加密」。實務系統還包含通道估計、同步與編碼等步驟。
